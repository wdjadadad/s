E听说答案提取 v2.0.0 —— 本机可用副本
======================================

■ 怎么用
  双击 启动.cmd
  → 会自动打开浏览器显示界面，同时留一个黑色命令行窗口（那是程序本体，关掉即退出）
  → 界面里点“扫描 / 刷新”，列表里出现 79644，点它就能看到
      ## 朗读（原文）
      ## 复述 / 表达（满分范文 4 篇 + 关键词）
      ## 其他（听力交际对话原文）
  共 7 个题块、5400 多字符，可一键复制或导出 txt。

■ 扫描目录
  默认：%APPDATA%\74656D705F74656D705F74656D705F74002
  这是本机 E听说 的题目缓存根目录，里面 79644\ 就是一份卷子，
  下分 content00010001 ~ content00010007 七个题块。
  想换目录：编辑 启动.cmd 里 set "ROOT=..." 那一行。

■ 为什么不用官方那个 Setup.exe
  官方 v2.0.0 的 Setup.zip 里的 PyInstaller EXE 在本机双击只会静默退出
  （进程存活不到 1 秒，exit code 0，无窗口无报错），
  和之前那个 DeepSeek 宠物 exe 的表现一样，疑似被火绒拦截。
  所以这里用的是同一份源码（etsx 包），由本机 Python 3.12 直接运行，功能等价。

■ 对源码打的一个补丁（重要）
  原版只认 content_* 这种目录名，而本机缓存用的是 content00010001 这种旧命名，
  导致整份卷子扫不出来。已修改：
    src\etsx\scanner.py  和  src\etsx\parser.py
    新增 _is_content_dir_name()，同时接受 content_3 与 content00010001
  改完后根目录扫描能把 79644 完整识别为 1 份试卷（7 个题块）。

■ 运行方式
  python run.py --web --root <缓存目录>
  纯标准库；vendor\ 里的 edge-tts 只用于朗读配音，缺了不影响提答案。
